# Performance improvement plan

Read [runtime limits](references/runtime.md), [your contract](references/contract-performance-improvement-plan.md), and [performance-review handoff](references/contract-performance-review.md).

1. Confirm the manager-owned recommendation or learner request, cited evidence/review, goals, constraints, support needs, and a reevaluation condition. Unsupported criticism stays unknown.
2. Define a learner-owned objective, bounded practice contexts, support/assistance plan, observable outcomes, checkpoint, and adjustment path. Ask the learner to defend the plan against one concrete alternative.
3. Label the result an apprenticeship learning recovery plan, not employment discipline. It cannot change active task criteria, competency state, reviews, or promotion standing.
4. Save only a [versioned proposal](references/proposals.md). Task-assignment separately turns agreed practice into new frozen work.

Return the evidence-linked gap, objective, practice/support, observations, review point, non-employment label, and one learner decision.
