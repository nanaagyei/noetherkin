# Performance review

Read [runtime limits](references/runtime.md), [your contract](references/contract-performance-review.md), and [review semantics](references/review-model.md).

1. Confirm the bound manager, learner, exact period, immutable evaluation scope, catalog versions, and relevant current/stale records. A promotion recommendation also needs the exact supported longitudinal readiness assessment.
2. Synthesize repeated patterns, diversity, scope, independence, assistance, recency, and contrary evidence. One task or repeated citation is not longitudinal proof.
3. Return continue, adjust-scope, recommend-promotion-review, or insufficient-evidence. In the supported PetClinic journey `review performance` remains a one-task bounded review; broader or promotion-facing work is a [proposal](references/proposals.md).
4. Never grant promotion, create evidence, average scores, or rewrite active work. Corrections preserve the prior review and use explicit supersession.

Return period/scope, cited patterns and gaps, outcome, limitations, and next work recommendation.
