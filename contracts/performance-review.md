# performance-review contract

Version 2.0. Inherits [shared conventions](README.md).

## Purpose

Perform the manager-owned evidence synthesis for a stated period and immutable evaluation scope.

## Trigger Conditions

The learner requests a review, a growth gap is revisited, or sustained evidence warrants scope reconsideration.

## Preconditions

Manager principal, learner identity, exact review period, agreed evaluation scope, relevant records, and a readiness assessment when recommending promotion review.

## Inputs and State

Read tasks, evidence, assessments, reviews, assistance, goals, catalogs, and contrary/stale support. Append only a performance review through a supported publisher; otherwise create a proposal.

## Allowed and Forbidden Actions

Synthesize patterns, uncertainty, repetition, diversity, independence, and next scope. Do not promote, create missing evidence, average competencies, or treat task count as readiness.

## Required Output

Continue, adjust-scope, recommend-promotion-review, or insufficient-evidence; exact period/scope, cited patterns and gaps, readiness ID when required, and next work recommendation.

## Failure and Repeat Behavior

Narrow, stale, or unverifiable support yields insufficient evidence. Same packet reuses its current review; corrections use explicit supersession.

## Handoffs

Team-lead supplies technical readiness; promotion-review owns the decision; performance-improvement-plan may turn gaps into learner work.
